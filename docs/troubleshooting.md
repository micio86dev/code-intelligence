# Troubleshooting

Start with `code-intel doctor`. Add `--log-level debug` to any command for engine invocations and stack traces (on stderr).

| Symptom                                                                                                                                       | Cause and fix                                                                                                                                                                                                                                                                                                             |
| --------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `[MISSING] semgrep ... exit 3`                                                                                                                | The engine is not on `PATH`. `doctor` prints the install command. Use `--allow-missing` only if skipping that check is acceptable                                                                                                                                                                                         |
| Exit 3 and `[ERROR] semgrep: exited with code 7`                                                                                              | Semgrep could not load its config. Usually offline with a registry ruleset (`p/default`). Go online or point `engines.semgrep.configs` at a local rules file/directory                                                                                                                                                    |
| Exit 3 and `[TIMEOUT]`                                                                                                                        | The engine exceeded the profile limit and was killed. Narrow the scope (`--changed`, `--since`) or raise `--timeout`                                                                                                                                                                                                      |
| `[ERROR] osv-scanner: ... (…)`                                                                                                                | Needs network access to the OSV API. Retry online, or exclude the category: `-e secrets,sast`                                                                                                                                                                                                                             |
| `Invalid .code-intel.json` (exit 2)                                                                                                           | Each problem is listed with its path. Unknown keys are errors by design, so typos do not silently disable a setting                                                                                                                                                                                                       |
| "N SAST finding(s) on unchanged lines were hidden"                                                                                            | Intended: you only own what you changed. See them with `--all` or `"lineFilter": false`                                                                                                                                                                                                                                   |
| A finding you accept                                                                                                                          | `code-intel baseline` once, then `scan --new-only`. Or add a `# nosemgrep` / `.gitleaksignore` entry, which the engines honor natively                                                                                                                                                                                    |
| `impact` says `method: heuristic`                                                                                                             | No CodeGraph index. Run `codegraph init` in the repository for transitive results                                                                                                                                                                                                                                         |
| `mutate`: "StrykerJS is not installed"                                                                                                        | `npm install --save-dev @stryker-mutator/core` in the project                                                                                                                                                                                                                                                             |
| `mutate`: Score is 0%                                                                                                                         | No mutant was detected. Check your test command really runs tests (a command that runs zero tests exits 0). If `NODE_TEST_CONTEXT` is set in your shell, unset it                                                                                                                                                         |
| `mutate` score is suspiciously high                                                                                                           | Your `npm test` probably also runs a linter or type-checker, which "kills" every mutant that breaks syntax. Point it at tests only                                                                                                                                                                                        |
| `--staged`/`--since` "needs a git repository"                                                                                                 | Run inside a git repository, or use `--all`                                                                                                                                                                                                                                                                               |
| `git` hooks (for example a global pre-commit tool) interfere in scratch repos you create                                                      | Not caused by this tool; use `git commit --no-verify` or `git init --template=` for throwaway repos                                                                                                                                                                                                                       |
| `npm install -g github:micio86dev/code-intelligence` fails with `EALLOWSCRIPTS` / `--allow-scripts is not allowed in project-scoped installs` | Observed with npm 11.16 when your npm config sets `allow-scripts` (check `npm config get allow-scripts`): npm refuses to pass it to the build of a git dependency. Install the prebuilt release tarball instead (no build step), or retry with that setting removed. The same install succeeded with an empty npm config. |
| Different results between two machines                                                                                                        | Registry rulesets and vulnerability databases change over time; pin semgrep rules locally for reproducibility                                                                                                                                                                                                             |

## `mutate` fails immediately: `ts.parseConfigFileTextToJson is not a function`

StrykerJS 10 rewrites the project's `tsconfig.json` using TypeScript's JavaScript API, which **TypeScript 7** (the native compiler) no longer ships. If your project uses TypeScript 7, tell Stryker not to touch a tsconfig, for example in `stryker.config.json`:

```json
{ "tsconfigFile": "tsconfig.stryker-unused.json" }
```

(any name that does not exist). This works when your tests run without compiling (Node's type stripping, Vitest, tsx...). This project's own `stryker.config.json` does exactly that.
